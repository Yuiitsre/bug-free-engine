# Lyrenthos — Phase 1

Godot 4.x procedural exploration prototype.

## Controls
- WASD: move
- Mouse: camera
- Shift: sprint
- Space: jump
- E: interact
- Tab: inventory
- Esc: release mouse

## Phase 1
- deterministic seeded terrain
- multiple biome families
- original procedural-style structures
- third-person controller
- atmospheric world presentation
- original visual language; no Minecraft assets/code
