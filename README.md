Windows 11 Desktop — Interactive Web Demo

A detailed Windows 11-inspired desktop simulation made with plain HTML, CSS, and JavaScript.

Run

Open index.html in any modern desktop browser. No build step, framework, package manager, or external dependency is required.

Features

- Windows 11-style desktop and wallpaper
- Centered taskbar with Start, Search, Task View, pinned apps, clock, system tray and notifications
- Start menu with pinned applications and recommended files
- App/file search and quick launcher
- Quick Settings with Wi-Fi, Bluetooth, Airplane mode, Battery Saver, volume and brightness
- Notifications Center
- Desktop icon selection and double-click launching
- Desktop right-click context menu
- Functional window manager: focus, z-order, drag, resize, minimize, maximize and close
- File Explorer simulation
- Microsoft Edge-style browser surface with local address bar behavior
- Editable Notepad
- Functional Calculator, including keyboard input
- Settings, Terminal, Clock, Photos, Paint, Store and Task Manager surfaces
- Lock-screen simulation
- Toast notifications
- Responsive layout for smaller screens

This is a browser simulation, not Windows itself. It intentionally uses browser-side state and local UI behavior rather than native Windows APIs.
