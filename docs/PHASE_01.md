# Lyrenthos — Phase 1: Insular Genesis

## Goal
Make a small but real playable foundation that can be expanded without rewriting the architecture.

### World
- deterministic procedural terrain
- five biome identities
- highland / meadow / wetland / arid / arcane terrain families
- three procedural-style landmark structures
- atmospheric daylight

### Player
- third-person prototype
- WASD movement
- Shift sprint
- Space jump
- Tab inventory
- E interaction hook

### Visual identity
Lyrenthos is not a Minecraft clone. Phase 1 uses original palettes, proportions, structures and materials, with a darker fantasy-adventure visual identity.

### Deliberate scope boundary
No combat, crafting, machines, animals, multiplayer, dimensions or advanced voxel meshing yet. Those are Phase 2+ systems.

### Next
Implement chunked voxel meshing, water/rivers, vegetation instancing, real inventory grid, wildlife and a proper title screen.
